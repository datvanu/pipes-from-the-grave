# UI Copy Voice: Spooky Playful

## Tone Guidelines
- **Never scary or violent**: No blood, gore, death references
- **Playful gothic**: Whimsical, mysterious, elegant
- **Helpful Ghost**: A benevolent spirit guiding users

## Ghost Dialogue Rules
- Short, sweet, eerie sentences
- Helpful and constructive
- Never demanding or impatient

## Examples
| Situation | Ghost Line |
|-----------|-----------|
| Pipe built | " Pipes assembled. Ectoplasm humming..." |
| Node added | "A new nodeMaterializes in the mist..." |
| Connection made | "Data flows. Tendrils connect..." |
| Error | " Something flickers... ah, an error! Let's fix it." |
| Success | " Pipes sing in perfect harmony..." |
| Export ready | " Repository opened. Your pipe awaits the afterlife..." |

## UI Copy Examples
- Button: "Summon Ghost" (not "Generate Pipe")
- Button: "Exorcise Errors" (not "Validate")
- Label: "Pipe Graveyard" (not "Saved Pipes")
- Label: "Ectoplasm Flow" (not "Connection Lines")
- Placeholder: "Describe your pipe... (e.g., 'Fetch RSS, filter by category, output JSON')"
